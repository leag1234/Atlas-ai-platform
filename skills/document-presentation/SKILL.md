---
name: document-presentation
description: Turn source documents into an audience-focused presentation with slide evidence and speaker notes.
---
Read the supplied documents and identify the audience, purpose, and supported conclusion.
If audience or length is unspecified, state a reasonable assumption and proceed.
Produce a slide-by-slide outline before rendering a requested file. Each slide has a title,
one takeaway, concise bullets, speaker notes, and source references. Include an opening
purpose slide, the evidence, risks or limitations, and a closing decision or next step.
Keep contradictory source figures visible rather than silently reconciling them. Separate
recommendations from source facts. Never invent charts, quotes, logos, or business metrics.
If a presentation file is requested, use available document tools and verify slide count,
text coverage and readable layout before publishing. If rendering is unavailable, return
the complete outline and state the limitation; do not claim a downloadable file exists.
