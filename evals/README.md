# ATLAS-0 evaluation pack — initial golden set

Generated on 2026-07-23 by Claude (Anthropic) — a model family **distinct** from the system
under test (Qwen/GLM/DeepSeek) and the judge: measurement independence is preserved.

## Statuses and provenance (required field on each case)

| `source` | Meaning |
|---|---|
| `verifie-web` | Answer key verified against a web source on the specified date |
| `genere-a-valider` | Generated by Claude, **must be validated by a human** before it is authoritative |
| `flores` | Taken from FLORES-200 (professional translations) via `tools/fetch_flores.py` |
| `incident` | Created following a bug/incident (to be continuously populated) |

| `statut` | `draft` → `valide` (by a human, `valide_par` field + date) |

**Rule: a `draft` case runs in reports (for information only) but does not count
toward GO/NO-GO thresholds until it is `valide`.** Your validation pass
(~1 min/case) consists of changing each `draft` to `valide` or correcting/rejecting it.

## M5 execution
`make eval` runs E1–E9 through the evaluation harness, persists the results to
SQLite, and writes `BRAIN/eval/report.html`, `report.json`, `telemetry.csv/json`,
and `calibration.json`. The HTML includes history/diff, languages, limits, and
measurement coverage. The sets and their statuses are retained.
`ATLAS_M5_MODE=record` mode replays already recorded calls and records missing
ones (series budget <3 EUR). `replay` mode, reserved for tests, requires exact
message matching and prohibits model calls.
`make eval-smoke` uses fifteen recorded cases, in at least three languages.
Replay times never constitute inference measurements: only provider/client
measurements archived with each response feed the dashboard.
CONTRADICTION resolved autonomously: E9 = five validated cases without FLORES;
PoC language distribution is indicative. Cross-calibration is informative; human
calibration remains pre-GA.
