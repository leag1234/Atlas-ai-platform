`slug.py` has no tests. Write a `unittest` test module `tests/test_slug.py` that checks every rule of the
`slugify` docstring. The tests must pass against the current implementation, and they will be judged by
running them against altered versions of `slug.py` that each break one documented rule: a good test suite
fails on every such alteration. Do not change `slug.py`. Standard library only.
