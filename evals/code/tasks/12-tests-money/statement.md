`money.py` (amounts in integer cents) has no tests. Write a `unittest` module `tests/test_money.py` that checks
every documented rule of `split`, `apply_discount` and `format_amount`. The tests must pass against the current
implementation; they will be judged by running them against altered versions of `money.py` that each break one
documented rule, and a good suite fails on every alteration. Do not change `money.py`. Standard library only.
