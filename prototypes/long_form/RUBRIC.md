# Scoring rubric (long-form prototype vs current Atlas)

Each criterion 0-4 (0 absent/wrong, 2 partial, 4 complete and checked). Scorer reads both answers in full and
checks numbers against the pages they cite (prototype: facts.json quotes; Atlas: its links, if any).

| Criterion | 0 | 2 | 4 |
|---|---|---|---|
| C1 Coverage of the request's expectations | most missing | about half, or present but shallow | every explicit expectation addressed concretely |
| C2 Correctness of numbers | an error that changes the reading, or numbers unverifiable | numbers mostly verifiable, one minor error | every checked number matches its cited page or a stated formula |
| C3 Diagrams on the subject's structure (only when asked) | none or generic | one relevant, no caption/reading guide | the requested diagrams, on the subject's own components/phases, captioned, readable |
| C4 Sources linked to facts | no sources | list without fact mapping, or weak sources | each source with the facts it supports, only pages read |
| C5 Pedagogy and structure | wall of text, thesis at the end | structured but thesis/verdict buried | thesis or verdict on top, progressive path, terms defined |
| C6 Length fit | badly over- or under-sized | somewhat off | size matches what the request asks |
| Time, cost | reported, not scored | | |

Total /24 (C3 counted only when diagrams are asked; otherwise /20 rescaled to /24).
Errors found are listed per answer; one factual error that a reader would act on caps C2 at 1.
