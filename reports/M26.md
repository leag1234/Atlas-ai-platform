## Changes

- Document-producing requests get a 300 s deadline (other requests keep 120 s); budget and quota refusals reach the user with the provider status, never as a provider outage (D5).
- Free pre and post audits of search credits before live batches (scripts/search_allowance.py); reserves 150 for Tavily and 50 for SerpAPI.
- Provider tool-call names above 80 characters (seen on GLM) no longer fail the request with HTTP 413: bounded recovery, accurate error, limit kept at 80.
- A requested file that was not produced triggers a model-driven recovery with forced tool use, then a content turn and a deterministic builder that writes the files from real content
  (never placeholder pages); the answer never promises a download that was not published.
- After a failed terminal operation the final answer must contain the requested content and must not promise a retry; promise-only or script-only answers are rejected with one bounded retry.
- Attachment filenames are not read as a request for a file deliverable (this had broken the recorded J45 replay).
- The recorded retry sequence of earlier journeys is unchanged; no cassette, gate assertion, prompt, threshold or protected file was edited.
