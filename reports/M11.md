# M11 — progressive streaming, validation in progress

POC-F1/F5, POC-P6, REQ-MOD-004, REQ-FIN-002. Prerequisite contract #49
merged after green CI: https://github.com/leag1234/cloclo/actions/runs/34507795404.
This CI proves only the contract; M11 is not yet complete.

The gateway decodes the provider UTF-8 stream, validates usage/finish/DONE, and
assembles tool arguments. The adapter immediately passes deltas through a queue
bounded to eight events. The streaming path uses serverless escalation, without a
GPU or retry after emission. M8 policy chooses the route before I/O and reserves
potential fallback within the EUR 0.05 budget. Provider reasoning is separated into
reasoning_content, disabled by default, enabled with reasoning_effort=low, under the
shared 2,048-token ceiling. Atlas metadata identifies turn, provisional/intermediate/final
phase, reservation, and cost. A visible “Intermediate step” label also distinguishes in
Open WebUI text preceding a tool from the final response.

make verify-m11 runs a barrier across two real HTTP connections: the client receives
the first fragment while the controlled provider still awaits acknowledgement before the
second. The BRAIN/eval/streaming.json report contains the fragment count, proof of
progress, measured cost, and duration. This test is deterministic and makes no paid
call; it is not a Scaleway benchmark. Tests also cover reservation before I/O, missing
usage, Unicode, separate reasoning, tool calls, closing, a slow client, and fragmented citations.
