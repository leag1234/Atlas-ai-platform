# M15 — developer API

REQ-DEV-001..005, AC-DEV-001..004; PR71/75 contracts merged before code.
The local 8030 entry point offers Chat Completions, Responses, and Messages, with a
default code model and no access to chat8020 private data. Hashed keys, atomic and
persistent UTC quotas, reservations before inference, cost per developer. Tools are
executed by the client; text SSE and incremental arguments.

## Limits and operation

RISK: the financial limit bounds available context below the window announced by the
provider; no arbitrary repository is guaranteed below EUR 0.05. Missing usage/cancellation/
restart: reservation retained. One code attempt only. No Responses storage, hosted tools,
or multimodal/thinking on this API. Claude Code compatibility with this provider is
experimental; future versions are not guaranteed. Profiles and key creation/revocation:
runbooks/devapi.md. NOTICED BUT NOT TOUCHING: public exposure/HTTPS and multi-user UI are
outside the PoC. CONTRADICTION: the current mandate permits the agent to squash after green
CI, replacing human merge in historical instructions. No threshold relaxed.
