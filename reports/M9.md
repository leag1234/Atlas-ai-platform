# M9 — memory and projects

Source: docs/15 M9; contracts/m9.md; REQ-ENG-002/004/005/007/009,
REQ-FIN-002 and POC-P6.

Projects group instructions, conversations, documents, and durable facts.
Document context and facts are shared only between conversations in the same project.
Facts are extracted automatically from the new user message; they can be inspected,
corrected, and erased. A revision invalidates in-progress extractions after
correction/erasure and removes old exchanges from active context. Archives remain inspectable.
Memory is explicitly distinguished from document citations.

The local interface is available at the adapter’s `/project-ui`, port 8020,
with `make serve` and an SSH tunnel. It offers project and conversation
selection/creation, instructions, textual notes/documents, chat, and fact editing.
Answers are rendered as text; only validated local citations create links.
Binary formats remain extractable with the M2 pipeline.

Project mode ignores client-provided history and loads context through the retrieval
API. It does not transmit memory to web search. Gateway calls share the existing
ceiling of 0,05 EUR and 120 s per request. Private storage remains local under BRAIN,
ignored by Git (directory 0700, file 0600). No GPU or new dependency is required.

## Verification

`make verify-m9` runs the protected verifier; `make test-memory` produces
BRAIN/eval/memory.json only after synthetic assertions succeed.
The gate is wired into existing CI through scripts/test.sh.

Tests cover persistence, reuse, document/citation scope, erasure/correction during
extraction, invalid transport, budget, errors, browser origins, and local proxy.
Real validation on three synthetic requests also confirmed extraction, reuse, and
erasure, for 0,0022254 EUR measured. No real-interaction journal was consulted.

Local results do not constitute milestone validation: the GitHub `ci` job must run
the gate and be green before final merge. Current CI evidence and progress are
recorded in BRAIN/STATUS.md.

PoC limits: local single user; fact selection by lexical relevance; basic interface;
HTTP UI and static DOM syntax/check tests, without an automated graphical browser.
Synthesis of large inputs belongs to M10.
