# M13 — sovereign image generation

Source: docs/15 M13, REQ-ENG-004/009, REQ-INF-012/013, REQ-FIN-002.

An explicit generation request in the chat calls the gateway, which alone
knows the GPU server. Return: PNG image encoded as a data URI in the
Markdown response compatible with the UI. Description must be non-empty,
limited to 2000 characters; minimal filtering of illicit requests before
transport. No external image downloads.
The image and its description are not saved in a versioned report except
in the synthetic verification case. Explicit errors, no secrets in responses.

The gateway calls a diffusers server on a Scaleway GPU from the dedicated project, restricted
to the client VM. Flux model configured in services/model-gateway. Sequential
execution: the optional text server is stopped during generation then
restored; the current PoC text remains serverless. PNG 512 × 512, four steps,
one image per request, exclusive lock and 120-second timeout. Estimated GPU cost
based on actual duration, refusal if the reservation at the observed rate exceeds 0.05 EUR.
Initial weight loading is measured separately from request time.

Deployment is scripted; ceiling 2 EUR/h, total M13 envelope 30 EUR attested
by MISSION. Cleanup via infra/gpu.py down in a finally block, even on failure.
Persistent weights may be retained in accordance with the M1 cycle.

make test-imagegen produces BRAIN/eval/imagegen.json from a real GPU generation
and a local HTTP read: image_produced, served_locally, dimensions, duration, estimated cost, and SHA256 fingerprint. Visual verification of the synthetic case
recorded in reports/M13.md. No success flag without effective generation.
make verify-m13 calls the protected script intact; CI calls its static mode
and deterministic tests without a paid provider.

Plan: GPU server and reproducible deployment; gateway transport; chat routing;
validation tests, filter, budget before I/O, unavailability, PNG return, and cleanup.
GPU dependencies isolated from the VM/CI, versions frozen and justified in the report.
No workflow, verify-*, nor CODEOWNERS modified.
