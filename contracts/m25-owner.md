# M25 owner requirements

The [original owner contract](m25-owner.txt) is binding, subject to the later
owner rulings in MISSION.md. It preserves the exact prompt reference and the
multilingual journey example. The archive is intentionally unchanged; the
English public overview follows.

D1 requires the four-layer general disposition prompt, below 3500 bytes.
D2 requires the three-domain generality policy. D3 separates public development
evaluation from owner-only independent evaluation. D4 measures conversations
against the model token window. D5 inventories and justifies production limits.
J50 checks the prompt, J51 checks a fresh design answer, J52 checks conversation
capacity, and J53 measures public corpus changes. Full criteria and exact wording
remain in the linked contract.
