# M2 — ingestion and RAG contract

Source: POC-F2/A3, POC-E1/E2/E3, REQ-ENG-002/004/009/011,
REQ-FIN-002 ; docs/11 R-02 and §9.2 ; scripts/verify-m2.sh (read-only).

## Contracts

- `make ingest` reads corpus/, extracts pdf/docx/md/html and persists chunks
  in Postgres + pgvector. Re-ingestion is idempotent and transactional.
- Chunk: stable chunk_id, doc_id, language, local source, non-empty text,
  position in the document, source fingerprint, finite embedding of constant
  dimension ≤ 1024. A content change explicitly invalidates old citations;
  an unknown identifier never resolves to another passage.
- Search: input is a non-empty question and an integer k between 1 and 8; output
  is an ordered list of unique chunks with scores. BM25 + multilingual embeddings
  + fusion then cross-encoder. Only the question enters the retrieval path: neither
  doc_id_attendu nor passage_attendu are accessible via this path.
- Generation via gateway only: question + retrieved passages; output is text
  and citations with chunk_id, each belonging to the retrieved passages.
  Prompts reside in prompts/, models in services/model-gateway/.
  Explicit refusal if sources are insufficient; typed error on invented citation.
- chunk_id resolution: exact passage and metadata persisted, or explicit
  not found error. No arbitrary source link executed by ingestion.
- `make eval-retrieval` produces BRAIN/eval/retrieval.json conforming to the
  adjacent schema. Recall = average of cases where both doc AND passage appear
  in top-8; MRR = average of 1/rank, zero if absent. Breakdown by language is mandatory.
  citations_resolues is true only after generating non-empty answers and effectively
  resolving all their citations; zero citations fail.
  Drafts remain indicative and do not constitute a validated quality GO.

## Implementation Plan

1. Preserve the questions and keys E1/E2/E3 now present; drafts remain
   indicative, without invented human validation.
2. Red tests for contracts, extraction of four formats, Unicode (including AR/ZH),
   empty/corrupted/too large files, idempotence, persistence and deletion.
3. Ingestion and index in services/retrieval; tested reversible migration.
   Embeddings/reranker on CPU behind gateway, no GPU nor live LLM call in CI.
   Dependencies to be justified (license, size, maintenance, alternatives) in the PR.
4. Retrieval tests with distractors, separation of questions/keys, real scores,
   then generation and citations with cassettes recorded in tests.
   Test provider errors, timeout, unknown citation and exceeded context.
5. Makefile, scripts/test.sh and evals/harness.py integrate the M2 gate into the
   existing ci job without touching protected files; no gate recursion.
6. Measure diff coverage ≥ 80 %, structured logs, latency and cost;
   document service/runbook/SLO, red proofs and validation limits.
7. Run make verify-m2 locally then branch/PR, wait for green ci, update BRAIN,
   stop M2. Split into PRs < 400 lines; agent merge authorized by the current
   mandate, only after green ci job.
