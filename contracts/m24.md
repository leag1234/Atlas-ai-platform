# M24 — Documents, files and visible execution

Status: draft; implementation and CI verification pending.
Source: MISSION.md M24/D1–D8 and owner journeys J42–J49, 2026-09-18.
Requirements: REQ-ENG-004/005/009/011, REQ-FIN-002, POC-F1/F3/F5.

## User intent before implementation

Read complete attachments, produce downloadable office documents, and modify
existing files without silently losing content or formatting. Show progress while
working and disclose extraction or search failures.

Six multilingual natural phrasings, including short, uppercase, unaccented,
English and German inputs, are preserved in tests/journeys/m24-cases.json.
They cover reading two attachments, correcting a document, comparing March,
creating downloadable slides, adding a chart while preserving formulas and
restructuring headings. Expand to six per capability under MISSION R2.
Negative case: "Explain how spreadsheets work; do not create or change a file."

## Boundaries and acceptance

- D1: `make serve` owns terminal startup/shutdown, a dedicated persistent user-file
  volume, and loopback port 8000. Load OPEN_TERMINAL_API_KEY without committing it.
  Configure the native UI connection by service name with filesystem uploads.
  Test original attachment bytes through the public UI/API, not only extraction.
- D2: enforce denial of terminal-originated access to host/internal services,
  metadata and private networks. Do not mount repository, platform credentials,
  Docker socket or host filesystem. Test denial from inside the container before
  enabling model execution, including ports 8010/8020/8030 and IPv6 paths.
  Authenticate download access and reject path traversal and escaping symlinks.
- D3: preserve sheets, columns and full document content for PDF, DOCX, XLSX,
  PPTX, ODT, ODS, ODP, CSV, TXT, MD and images. Explicitly identify protected,
  scanned and failed extractions. Attachments must not query corpus retrieval.
- D4: deliver nonempty, structurally valid DOCX/XLSX/PPTX/PDF/CSV/MD/PNG through
  actual downloadable UI files. Validate downloaded bytes with format readers.
  Use soffice for PDF conversion and keep visible conversion progress.
- D5: state whether transformation regenerates or edits in place. Preserve
  untouched styles, images and formulas when editing; disclose regeneration's
  formatting loss. J44 checks exact figures and an embedded chart in a new sheet.
- D6: inspect a real rendered answer before changing CSS; target stable DOM
  classes without generated suffixes. Capture before/after browser screenshots,
  light/dark computed styles, serif prose and absent default code furniture.
- D7: prove emission, transport and rendering of named activity within two seconds
  on a no-tool request; elapsed time updates until visible answer text. Capture
  a screenshot during real generation, not an isolated component demonstration.
- D8: attachments receive a 0.30 EUR ceiling; ordinary requests retain 0.10 EUR.
  Above the attachment ceiling, use bounded M10 hierarchical synthesis. Tavily
  search supplies page content directly; do not refetch its search results.
  Retain explicit SerpApi provider selection and disclose quota/provider failure
  in the answer. Never silently substitute model memory for failed research.

Keep all other tools read-only. The owner explicitly superseded POC-W3 only for
the contained Open Terminal path. No additional cloud resource is required.
