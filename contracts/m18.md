# M18 — conversation integrity and image fidelity

Source: MISSION M18 D1–D6/J9–J14; REQ-ENG-004/009, REQ-FIN-002, POC-F1/F3.
This contract supersedes the M13 image dimensions and inline-history transport.

Resolve project scope before classifying a follow-up. Transformations of the previous
answer bypass retrieval, web and vision. Project history comes exclusively from the
validated server conversation. Existing source links remain references.

Generated images are stored locally under opaque references and served by the chat
adapter. Only references and bounded descriptions enter model history. Legacy inline
assistant images are removed before text-context validation. Iteration generates a
new image from the prior description and requested changes; it is not pixel editing.
An uploaded image does not override the user's intent. Editing requests receive an
explicit explanation of the unsupported operation and available alternatives.

Web timeouts receive one automatic retry with a different query/source before final
failure, subject to the existing shared tool, search, time and cost budgets. No fresh
ledger for a retry. Interface labels come from fixed resources using the UI locale.

Image generation keeps the gateway's configured model. Output is PNG 1024 × 1024,
with a random seed returned to the caller; supplying that seed allows reproduction.
The gateway rewrites requests into structured English subjects, attributes, scene and
style, preserving all explicit constraints. Log original and rewritten text, seed,
settings and cost, without image bytes. Sequence length is 512; overlong tokenized
prompts fail explicitly instead of silent truncation. Guidance remains zero.
The GPU worker watchdog is 180 seconds; request deadlines and the combined rewrite
plus generation reservation remain bounded by 120 seconds and EUR 0.05.

Compare four and eight inference steps with matched prompts and seeds on the real
worker. Report image evidence and per-constraint vision judgments. Keep the better
setting; on equal quality prefer lower latency/cost. No fabricated provider replay.

Public API journeys J1–J14 prove the changes and non-regression. J14 records original
prompt, rewritten prompt, seed, image reference and per-constraint findings; fewer
than three satisfied constraints are reported, not hidden. J8 remains a separate
startup check. Protected verifiers and CI workflows remain unchanged.
