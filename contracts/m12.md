# M12 — Sovereign Image Input

Requirements: docs/15 M12; REQ-ENG-004/005/009, REQ-FIN-002,
POC-P6. Additive extension of contract M7, prerequisite to implementation.

## Public Entry and UI

POST /v1/chat/completions preserves text messages. User content
can also be a list of OpenAI-compatible parts:
- {type: text, text: non-empty string};
- {type: image_url, image_url: {url: data:image/png;base64,...}}
  (JPEG also accepted; detail auto/low/high optional).

One to four images per request, at most 2 MiB decoded per image and 4 MiB
in total; positive dimensions, at most 4096 per axis and 16 million pixels
cumulative. Real format validation, strict base64, absence of truncated
files; no remote URL downloads, disk access, or SVG.
The HTTP body is bounded before parsing (6 MiB). Images are accepted
only in user messages; a text question remains mandatory in the
last message. Historical text limits remain applicable.

Native Open WebUI upload transmits the image as a data URI. Verify this
configuration and a complete multimodal request; do not announce browser
validation based solely on an HTTP test.

## Gateway and Processing

Any request containing an image uses a dedicated internal vision endpoint;
only the gateway knows the vision model and its rate, configured in
services/model-gateway. Provider: Scaleway Generative APIs, no local
GPU. Images and history are transmitted to the vision model, without conversion
into a supposed simple description nor fallback to a text model.
Prompt instructions live in prompts/. Side-effect tools
remain absent. The M7 text path retains its behavior.

Conservative reservation before inference: text, maximum envelope of image
tokens and output, at the configured rate; rejection before transport if >0.05 EUR.
Actual usage controlled, conservative cost maintained if usage is absent or invalid;
total ceiling 120 s, output at most 2048 tokens. No hidden retry.
M7-compatible return: text, usage, observation escalade/complexe and cost.
Typed errors: invalid/bulky input, budget, timeout, provider;
no raw exception, key, image payload or header in errors.
SSE preserves the atomic M7 contract until integration of M11.

## Observability and Proofs

Local log: text question, response, number/format/dimensions of images,
vision route, tokens/cost/latency and errors; never the bytes/base64 of images.
No real interaction leaves BRAIN/interactions, ignored by Git.

make test-vision tests description and content question on a synthetic
versioned image without secret. In live mode: bounded Scaleway requests,
synthetic recordings and measurements; in CI: replay of these recordings,
no live LLM call. Report BRAIN/eval/vision.json: described true only
if semantic assertions of both responses and routing are verified.
Negative tests: invalid format, base64, limits, private/remote URL refused,
image only, forbidden role, budget before transport, timeout, absent usage,
image never logged, text non-regression. make verify-m12 calls the protected
script intact; scripts/test.sh includes the gate and its replay in the existing CI.
