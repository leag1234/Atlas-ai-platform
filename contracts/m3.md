# M3 — Harness and Read-Only Tools

Source: docs/13 POC-F3/F4/F5, W1..W5, P6 ; docs/06 REQ-HAR-001/002/006,
REQ-TOOL-001/002/004/012/013/014/015 ; REQ-FIN-002.
Contract and implementation in the same PRs authorized by mandate M3.

Tool inputs: strict objects, additional properties refused.
- calculator : expr, arithmetic string <= 512 characters; decimal numbers,
  parentheses, + - * / only. Exact decimal result, explicit error.
- rag_search : non-empty query <= 4000 characters; search via M2 contract.
- web_search : non-empty query <= 4000, n integer 1..5 (default 5),
  lang fr/de/es/it/en, news boolean (default false). SerpApi Google/News,
  localization by language; title, URL, snippet and date available.
- web_fetch : public HTTP(S) URL, no credentials, <= 4096 characters.
  DNS and redirects validated, connection pinned to a public IP; robots
  fail-closed, timeout <=15s, body <=2MB; trafilatura, 8000 tokens maximum,
  handle local for subsequent steps, cache 24h. Text untrusted, URL and UTC date.

Harness request: non-empty question <=32000, explicit language among five languages.
Budget configurable downwards only: 10 tools, 120s, 0.05 EUR,
16384 tokens (M3 operational choice; POC-P6 does not specify a token limit).
Cost/token reservation before I/O, timeout bounded by global deadline. No paid call
without configured rate; timeout does not cancel billing already incurred.
Maximum 3 searches, 8 fetches; identical repetition three times: stop.
States: model, tool, done, stopped. Output: text, stop reason, trace,
consumption and references. Typed errors visible to the model, never swallowed.
Search: 1h cache, persistent monthly quota, refusal at 900 reserved searches
out of 1000; failures may retain their reservation (conservative bound).

AC: invalid schemas/arguments, exact calculation and attacks, private IPv4/IPv6,
mixed DNS/rebinding/redirects, robots, sizes/deadlines, caches/quotas,
four budget stops in integration; traces E4 >=90%, E6 end-to-end.
Real provider exchanges are recorded for replay under tests only.
Draft keys and uncalibrated judge do not constitute an E6 quality GO.

Full plan: BRAIN/m3-plan.md. M3 scope only, no GPU; additional cloud cost 0 EUR/h.
PR by increment if necessary for REQ-ENG-008 (<400 lines).
Protected files unchanged. CI of exact SHA required before each merge.

Gateway (same URL as M2): POST /agent/config with {} returns only
input_eur_per_mtok, output_eur_per_mtok and max_tokens (2048). Rates provided
manually in services/model-gateway/pricing.yaml, no identifiers exposed.
POST /agent/complete : {messages: list of objects <=100, tools: list <=4,
timeout: seconds <=120}. Response {text, usage:{prompt_tokens,completion_tokens}, calls:[{id,name,arguments}]} ; errors
provider_error/invalid_input, never raw provider response in error.
Conservative initial reservation: number of UTF-8 JSON bytes + 256 framing tokens,
plus 2048 output tokens; cost calculated with these bounds. After complete response, reconciliation with validated provider usage lower than reservation. Timeout/error retains entire reservation.
SerpApi Starter: fixed subscription, hard quota 900 searches/month; marginal cost
zero within the plan, no paid overage authorized. Fixed cost tracked separately.

Initial extracts: web <=2000 UTF-8 bytes (remainder behind handle), RAG <=400
bytes per passage (chunk_id resolves full passage M2). Ceiling 8000 tokens
retained, lower limits to leave room for iterations.
Local harness API POST /query (Query) ; GET /continuation/{handle}?offset=0
returns untrusted text and next_offset; expired handles 404. No external writes.

After each valid response, the provider prompt_tokens count of the exact prefix
is reused; only new messages are reserved in UTF-8 bytes + 256 framing tokens,
plus maximum output. If the prefix changes, revert to full bound. Cumulative limits remain identical; usage exceeding reservation triggers provider_error. Tests for modified prefix and cumulative cost.
