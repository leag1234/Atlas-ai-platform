# M11 — Progressive Streaming and Separated Reasoning

Requirements: POC-F1/F5, POC-P6, REQ-MOD-004, REQ-FIN-002,
REQ-ENG-004/005/007/009; docs/15 M11. Extension of M7 contract.

## Public Stream

POST /v1/chat/completions retains its JSON contract when stream=false.
With stream=true, response is text/event-stream: JSON data events
chat.completion.chunk, stable identifier, progressive delta.content,
terminal event finish_reason and usage, then data: [DONE]. No artificial
splitting of an already completed response. The first delta must be able
to reach the client while the provider is still waiting before producing
the rest.

Internal tools remain executed by the bounded harness. Their arguments are
never presented as assistant text. Any intermediate text is distinguished
from the final response. Document citations only become links after resolution
against the passages actually retrieved.

Option reasoning_effort: none by default, low upon explicit request. If the
provider exposes reasoning or reasoning_content, normalize to
delta.reasoning_content,
separated from content (compatible with Open WebUI reflection display). No
fabricated reflection when the provider returns none. Atlas metadata indicates
activation, the shared output ceiling, and the reserved cost; reflection tokens
are part of the billed output, not an additional budget.

After SSE headers, errors are error events with a typed code without provider
details, followed by [DONE]; never a successful finish_reason=stop on an
incomplete stream. Validation errors before opening remain JSON 4xx.
Cancellation/disconnection closes the upstream stream and cancels the generation
task. A single local log is written, including cancellations, without secrets.

## Gateway Boundary and Budgets

Internal extension /agent/stream: same input as /agent/complete, plus
reasoning_effort none|low; SSE output of deltas and validated terminal result
(text, assembled calls, usage, observation), or typed error. Model names and
secrets remain exclusively within model-gateway.

UTF-8/SSE fragments and fragmented tool calls are assembled with explicit
limits. The stream is invalid if provider usage or end is missing.
The timeout includes the entire read, queues are bounded; no retry after
text emission. Cancellation closes the provider HTTP connection.

Each call remains reserved BEFORE I/O in the existing ledger: total output
at most 2048 tokens, request at most 16384 tokens/10 tools/120 s/0.05 EUR.
Unknown usage after stop: reservation retained. Reflection bypasses neither
the output ceiling nor the financial ceiling. No GPU required.

## Verification

make test-streaming produces BRAIN/eval/streaming.json: number of content
deltas, proof of reception before upstream end, time and cost/reservation.
make verify-m11 calls the unchanged protected verifier; scripts/test.sh
executes it in the existing CI job. Local network tests to a recorded
provider or controlled transport exclusively within tests, without paid LLM
calls in CI.

Cases: real progression with provider barrier, fragmented Unicode,
fragmented tool calls, separated/absent reflection, resolved citations,
missing/invalid usage, truncated stream, provider error, timeout, cancellation,
slow client, refusal before call when budget insufficient. A synthetic Scaleway
probe can provide a cassette, capped at 0.05 EUR/request; no reading or
publishing of real interactions.
