# M5 — Full Evaluations and Telemetry

Requirements: POC-F7/F8, POC-R1–R4, POC-E1–E9/EL,
REQ-ENG-004/007/009/011, REQ-FIN-002.
Contract and implementation in the same PR are authorized by mandate M5.

## Results
Each observation includes suite, identifier, language, normalized score [0,1],
status (valide/draft/stale), response, and evidence. Draft statuses are
indicative; stale is excluded. Business keys are never transmitted to the
evaluated system. Judges receive response, question, rubric, and evidence.
Quality scores [1,5] are divided by five in aggregates.
Reports retain counts and thresholds per suite and per language.
A missing, infinite, out-of-range, or duplicated result is an error.

## Cross-Calibration
Sample fixed before scoring: 30 responses, six per language FR/DE/ES/IT/EN.
Two independent integer scores [1,5] per response, same rubric; no score from one judge is given to the other. Raw agreement, mean absolute disagreement, and
global and per-language unweighted Cohen's kappa. If expected agreement equals 1,
kappa is undefined: explicit error, never arbitrary replacement by 1.
Inter-model calibration is informative for the PoC, not a pre-GA human validation. The reference choice is that of MISSION and the final clarification in docs/13.

## Telemetry and Reports
Input/output tokens, cost in EUR, latency in seconds; TTFT and throughput are
measured from the provider stream. Cache hits come solely from a provider measurement. An unavailable measure is null with its provenance.
Timestamped JSON and HTML report, diff against the previous comparable run,
linguistic breakdown, CSV export, and durable storage. The dashboard exposes
the measures and their coverage, including unavailabilities.
Total duration <1200 s, cost <3 EUR; smoke test 15 cases, >=3 languages, <180 s,
<0.30 EUR. Bounds verified before calls then on returned usages.
In CI, only tests inject recorded provider responses; no replay/mock in executable application branches.

## Acceptance
Negative tests: empty/non-finite inputs, missing languages, invalid scores,
degenerate kappa, duplicate identifiers, absence of evidence, budget/time overruns, untrusted HTML. Integration tests for persistence/diff and transport.
Run `make verify-m5` locally then green CI job for the published SHA before squash merge.
No protected files modified, no GPU required, no M6 work.

## Prepared Transport
The gateway selects system/production/reference roles and their rates.
POST chat/completions in SSE with final usage required; premature EOF, finish_reason
other than stop, invalid usage, and cost exceeding reservation are errors.
TTFT = arrival of the first content fragment; tok/s = output tokens / duration
between first and last fragment (null if a single instant). Catalog cost non-discounted, conservative; cache = cached_tokens / prompt_tokens only if provided.
Versioned rubric: prompts/eval-judge.txt; no reference results transmitted
to the tested system nor to the production judge. Integration into the harness remains to be done.

## Preparatory Work Not Integrated
Aggregation of scores and linguistic gaps, escaped HTML report, diff against
the previous report, CSV of measures, and local SQLite history prepared.
Coverage validation, target storage, and the complete harness remain
to be integrated. The Linux CLI transport applies an absolute interruptible timeout of
120 seconds, even when an SSE stream sends bytes slowly.

## Text Transport Resumption Authorized (MISSION)
Judges request JSON per prompt without strict response_format. The client
extracts the first syntactically valid object and strictly validates its fields,
without modifying a score. An invalid score never becomes a success.
Transport errors are archived separately; any calibration exclusions are announced with identifier and reason, in accordance with MISSION.
CONTRADICTION resolved autonomously: E9 uses five validated cases; languages are indicative
for the PoC, without changing business keys or score thresholds.
The PoC calibration function retains the preselected list and explicit exclusions.
Global κ must be calculable to verify M5; a constant subgroup may have an undefined κ (null and reason), even if the global is numeric.
The PoC gate retains average thresholds and critical failures. Language gaps (target POC-EL "eventually") remain in quality_go, distinct from poc_passed.
The report is a quality NO-GO if this target is not reached, even if M5 correctly produces all its measures. The refusal rubric concerns zero invention.
