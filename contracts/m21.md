# M21 — Expert answers, three provider models and complete evidence

Requirements: MISSION M21 D1–D5, REQ-ENG-004/005/009/011, REQ-FIN-002,
POC-F1/F2/F4/F5. The latest owner decision of2026-09-17 and updated protected
verifier supersede the abandoned deep-mode clauses archived in decisions-log.

The public selector exposes exactly atlas, atlas-glm and atlas-fast. Each pins
its configured gateway provider role. All generation calls explicitly send none,
including recovery and evaluation. Each public model has3000 output tokens,
120 seconds,0.10 EUR and10 tools; user input cannot increase these limits.
Legacy internal clients retain2048 output tokens and0.05 EUR. Prompts and tools
are shared. Unsupported vision selects a configured compatible alternate and
reports fallback. Provider identifiers and prices remain inside model-gateway.

All provider replies are untrusted and validated. Empty/whitespace content,
length finishes, non-null error bodies, invalid usage and echoed serialized
tool-history envelopes cannot silently succeed. Before answer emission, one
full-context recovery is permitted within the same financial/time ledger.
Malformed recovery fails explicitly. After ordinary answer text has been emitted,
interruption is reported; never concatenate a restarted derivation. Standard
streaming holds only potential malformed-envelope prefixes. Unknown usage remains
reserved; known usage releases unused reservation. No third provider attempt.

Output allowance includes any unexpected reasoning. Trace/answer accounting uses
provider usage when supplied and labels estimates. Empty content with nonempty
trace logs provider_default_regression, retries with explicit none when affordable,
and surfaces the incident. Trace details are separate and collapsed. Log effort,
trace tokens, answer tokens, retry/fallback and cost per request.

The adapter emits activity immediately and elapsed seconds while inference is
pending, naming tools and consulted URLs. Tool/trace details are collapsed above
the answer. User messages have a green background in the existing Open WebUI.

Download within the existing2 MB cap, extract before budgeting, then deliver whole
extracted text and complete RAG chunks when they fit token budgets. Oversized
sources receive bounded hierarchical evidence selection with relevant passages
and explicit coverage/provenance; disclose incomplete coverage. Multiple technical
identifiers retain separate relevant windows. Existing SSRF, robots and untrusted
source rules remain. Finalization retains historical calls/results losslessly as
untrusted assistant context; omit active schemas only for answer-only generation.
Reserve the larger JSON-escaped representation before I/O. Never drop evidence to
silently fit a budget.

Store validated uploads once using opaque local references; history carries
references and only current evidence is materialized. Existing image byte/pixel
limits remain. Ten turns with a distinct photo remain usable. Return references
so clients can avoid retransmitting base64. No arbitrary URL retrieval introduced.

Validation: J27 compares useful technical answers to the same original question
on all three models and reports actual costs and the original detailed derivation
quality metric, including failures. J28 deliberately exhausts output allowance to
verify bounded recovery or an explicit public error. J29–J33 retain the original
photo, article, RAG-tail citation, named tools and timely activity. Real external
exchanges are recorded for HTTP replay in CI. Unit tests cover exact selector,
outgoing none, malformed replies, ceilings/accounting, cancellation, evidence,
ten-turn image references and malicious references. No fabricated recordings.

The public model enumeration is published as contracts/m21-profiles.json; runtime
validators consume that data rather than hard-coding provider-derived aliases in
Python. Gateway routing.yaml maps those public names to configured provider roles.
The mapping must match the published enumeration before inference is permitted.

Evaluation shares the explicit-none requirement. Its system, production judge and
reference must be distinct models; the reference defaults to the configured fast
model rather than a reasoning-only model. Reacquire calibration for that reference,
and match model identity in evaluation replay. Existing0.05 EUR/call and3 EUR/series
evaluation ceilings remain; reference-family changes never relax score assertions.
