# M15 — Local Developer API

Source: docs/15 §M15 ; REQ-MOD-004, REQ-FIN-002, REQ-ENG-002/004.
Protocol references: developers.openai.com/api/reference/resources/responses,
learn.chatgpt.com/docs/config-file/config-advanced,
code.claude.com/docs/en/llm-gateway-protocol.

REQ-DEV-001: Distinct developer FastAPI service, loopback8030, accessible via
SSH. All routes require a random API key of at least 256 bits; Bearer
(OpenAI) or x-api-key (Messages). Two different credentials are refused.
Identity derives exclusively from the validated key; no declarative client
identity is used for authorization or billing. Keys stored hashed SHA256 in local
SQLite 0600; local administrator creation/revocation, secret delivered in an
exclusive 0600 file, never stdout. No provider key delivered to clients.

REQ-DEV-002: Daily UTC quota per developer, in requests and micro-euros;
atomic SQLite reservation before provider I/O, concurrent transactions tested.
Insufficient balance 429, missing/invalid/revoked key 401. Actual cost reconciled with
provider usage; missing usage, timeout, cancellation, or restart preserves the
entire reserve. No speculative refunds nor retries after SSE emission.
GET /v1/usage exposes only the authenticated developer's counters. Logs
without content or keys: request/dev identifier, duration, tokens, cost, status.

REQ-DEV-003: POST /v1/chat/completions, POST /v1/responses, and POST /v1/messages
expose text and functional tools provided by the client. Tools are
executed exclusively by the client; no access to the assistant's shared RAG, files, history, or
MCP. GET /v1/models announces atlas-code, an internal alias without a provider
identifier. The gateway chooses its code role; models/rates remain
exclusively in services/model-gateway. UI8020 adapter unchanged.

REQ-DEV-004: Multi-turn messages, multiple calls with stable identifiers,
fragmented JSON arguments, correlated tool results, tool_choice, finish reasons,
usage, and cancellation. SSE truly incremental for text AND arguments, proper
termination following each protocol. Truncated output marked length/max_tokens/incomplete,
never misleading stop. Responses without server storage (store=false), history
returned by the client; no previous_response_id nor OpenAI-hosted tools.
Messages text/tool_use/tool_result; functions JSON Schema; multimodal
inputs or unimplemented options explicitly refused, never silently ignored.
Documented metadata fields with no effect are validated separately.

REQ-DEV-005: Body bounded to 1MiB, delay 120s, context limited to the model's capacity
AND to a ceiling of 0.05EUR per request. Conservative reservation of input tokens
(serialized UTF8 bytes + protocol margin) and maximum output BEFORE transport.
No silent code truncation. 400 responses for incompatible context/budget/options;
generic provider errors 502. Large code context tested with at least 24KiB of
useful input; financial limits published, without claiming an arbitrary
repository fits under 0.05EUR. For this API, a single code attempt allows
allocating the budget to the context; no change to the M8 chat fallback.

AC-DEV-001: Missing/invalid/revoked authentication, distinct keys, absence of
leakage between developers, and concurrent/persistent quota verified without provider.
AC-DEV-002: Conversation text→function→result→response, multiple tools, unicode,
fragmented arguments, error/timeout/disconnection/truncation on all three protocols.
AC-DEV-003: Large context actually sent, excessive context and cost refused
before I/O, actual cost per key and unknown reserve observable.
AC-DEV-004: Real Codex and Claude Code, frozen versions, each performing a
synthetic task in an isolated folder; result tests executed outside the model. No
cloud/GitHub keys nor personal configuration accessible to clients. Claude Code
connection to a non-Claude model is experimental, not supported by Anthropic.

make test-devapi generates the six indicators BRAIN/eval/devapi.json after assertions;
make test-devapi-e2e uses the real provider under the ceiling. Sanitized synthetic
proofs and versions in reports/M15.md; fixtures only in tests, CI without
secrets. make verify-m15 protected unchanged; invocation added to the test launcher.
Contract and SQL schema merged before code; targeted increments under 400 lines each.
No GPU, no public/HTTPS/multi-user UI exposure in this milestone.
