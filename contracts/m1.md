# Contract M1 — Reproducible GPU Infra + Gateway (Minimal PoC Version)

## Goal
Prove that a GPU node is created by script, serves a model via vLLM, and then
is destroyed by script. Nothing more. Metrological rigor (TTFT to the chunk,
multi-cycle reproducibility) is deferred to phase 2.

## Validation
The proof of M1 is the successful execution of `make verify-m1` **on the VM** (with
Scaleway credentials), NOT a GitHub CI run (which has neither GPU nor secrets).
In CI, `verify-m1` performs only static control of the scripts.

## Deliverables
- `infra/gpu-up.sh`: creates the GPU node, mounts the persistent weights volume,
  launches vLLM with prefix caching enabled, writes the IP to `BRAIN/gpu_ip.txt`.
- `infra/gpu-down.sh`: destroys the instance (preserves the weights volume).
- `services/model-gateway/`: routing configuration (local + fallback).

## What `verify-m1` verifies on the VM (single cycle)
1. `gpu-up.sh` creates the node from scratch and produces an IP.
2. vLLM responds HTTP 200 on `/v1/models` (readiness, max 12 min).
3. A control inference on `/v1/chat/completions` returns a valid completion;
   total duration and approximate throughput (tokens/s) are measured.
4. The result is archived as JSON under `BRAIN/bench/` (free format: at least
   `ip`, `total_s`, `output_tokens`, `tokens_per_s`, `ts`).
5. `gpu-down.sh` destroys the node.
6. The full cycle takes less than 20 minutes.

A trap guarantees GPU destruction upon exit, even in case of failure, to never
leave a billed GPU idle.

## Out of Scope for M1
TTFT measured at the first SSE chunk, second reproducibility cycle, compliance
with a strict schema, GPU execution in CI. Deferred to phase 2 if the PoC succeeds.
